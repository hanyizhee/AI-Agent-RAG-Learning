# 网络模型

互联网(Internet)连接了数以亿计的设备,网络四通八达就如同时城市的复杂的道路。网络中传输的数据就像是城市道路中的车流,如果不加以管理那必然会出现混乱。在国际ISO组织就统一了程序在网络中通信的模型和标准。包括:

- **OSI网络模型**:全球网络互连标准模型
- **TCP/IP网络模型**:可以认为是OSI的简化版

## 二、TCP/IP四层网络模型

### 1.应用层
>**协议**: HTTP、 FTP、SMTP
- 将用户与应用程序交互的数据按照协议格式进行封装
- 如果是 HTTP 协议，那么为数据添加 HTTP 头，此时数据被称为 HTTP 报

#### 深入：HTTP 协议详解
- **概念**: Hyper Text Transfer Protocol,超文本传输协议,规定了客户端和服务器之间数据传输的规则。(只有在请求及响应中都遵循了统一的规则,服务端才能读懂客户端发送来的请求,客户端才能解析服务端响应的结果)
- **特点**：
1. 基于文本的协议：请求和响应的部分的协议内容为文本格式,底层通过 TCP 协议传输,稳定性强。
2. 基于请求-响应模型：一次请求对应一次响应,必须由客户端先发起请求,服务端才会返回响应。
3. 无状态：服务端不会记忆与客户端的历史交互信息,每次请求-响应都是独立的。

### 2.传输层
>**协议**: UDP、TCP
- 负责将数据准确送到到对应的应用程序(端口)
- 加 TCP 头，此时数据被称为数据段
- 加 UDP 头，此时数据被称为用户数据报

### 3.网络层
>**协议**: IP
- 负责基于IP地址将数据包路由给对应设备
- 加上 IP 头,此时数据段被称为数据包

### 4.网络接口层
- 负责数据在物理网络中的传输,处理与硬件设备交互
- 为数据包添加帧头帧尾，此时数据被称为数据帧
