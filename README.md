# Python 函数学习笔记

> 记录我从零开始学习 Python 函数的完整过程

---

## 📚 学习内容

### 第1天：函数基础（basic.py）
- ✅ 函数介绍
- ✅ 函数定义（`def`）
- ✅ 函数参数与返回值（`return`）
- ✅ 函数说明文档（docstring）
- ✅ 函数嵌套应用
- ✅ 案例练习

### 第2天：函数进阶（advanced.py）
- ✅ 变量作用域（`global` 关键字）
- ✅ 传参方式（位置参数、关键字参数）
- ✅ 默认参数（缺省参数）
- ✅ 不定长参数（`*args` 和 `**kwargs`）
- ✅ 参数类型（函数作为参数）
- ✅ 匿名函数（`lambda` 表达式）
- ✅ 案例1：递归函数
- ✅ 案例2：电商总金额计算系统

### 第3天：模块与类型注解（module_intro.py）

- ✅ 类型注解
  - 变量类型注解（`name: str = "张三"`）
  - 函数参数类型注解（`def greet(name: str) -> str:`）
  - 函数返回值类型注解（`-> str`）
  - 类型推断（编辑器自动识别类型）
- ✅ 模块介绍
  - 什么是模块（`.py` 文件）
  - 模块的作用（代码复用、命名空间隔离）
- ✅ 导入模块的方式
  - `import module`（导入整个模块）
  - `from module import func`（导入特定功能）
  - `import module as alias`（起别名）
  - `from module import *`（导入所有，不推荐）
- ✅ 自定义模块
  - 创建 `.py` 文件作为模块
  - 模块中的全局变量与函数
  - `if __name__ == "__main__"` 的作用
- ✅ 模块包（Package）
  - 包的概念（包含 `__init__.py` 的文件夹）
  - 包的作用（组织多个模块）
  - 包的导入方式（`from package import module`）

### 第4天：面向对象基础（oop/）

- ✅ 面向对象概述（`oop_intro.py`）
  - 什么是类（Class）：对象的蓝图/模板
  - 什么是对象（Object）：类的具体实例
  - 面向对象编程思想（OOP）基本理念
- ✅ 类与对象基础（`class_basic.py`）
  - 类的定义（`class关键字`）
  - 对象的创建（`类名（）`）
  - `self`参数的作用
- ✅ 实例方法与魔法方法（`instance_method.py / magic_method.py`）
  - 实例方法的定义与调用
  - 方法中访问实例属性
  - `__init__`：初始化方法（构造方法）
  - `__str__`：d打印对象时显示的字符串
- ✅ 实例属性与类属性（`attritube.py`）
  - 实例属性：属于每个对象自己（`self.xxx`）
  - 类属性：属于类本身，所有对象共享
  - 属性查找顺序：实例属性 > 类属性
- ✅ 案例 -- 教育管理系统（`case_course`）
  - 综合运用类、对象、属性、方法
  - 实现学生成绩的增删改查功能
  - 菜单交互与业务逻辑分析

### 第7天：异常（exceptions/）

- ✅ 异常基础（`exceeption_basic.py`）
  - 什么是异常（exception）：程序运行那个过程中出现的错误，他会中断程序的正常执行流程
  - 什么是异常处理（exception handling）：不做处理/捕获异常
  - 什么是异常传递（exception propagation）：就是在函数调用中层层上报的过程，直到有人处理它，或者程序崩溃
- ✅ 异常案例（`exceeption_demo.py`）
  - 当前函数能把问题修复好 -> 就地 except 捕获，到此结束，不上抛
  - 当前函数不知道怎么办 -> 不捕获,抛给调用你的上层
  - 最顶层入口:只做兜底,捕获意外未知错误,用来记录日志、优雅退出,不作为主要业务处理位置
